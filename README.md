# คู่มือผู้ใช้ Baymax — PWA

คู่มือหน้าเดียว ติดตั้งเป็นแอปบนมือถือ/เดสก์ท็อปได้ และอ่านได้แม้ไม่มีเน็ต

## ไฟล์ในชุดนี้

```
index.html              หน้าคู่มือทั้งหมด + UI ชวนติดตั้ง
manifest.webmanifest    ชื่อแอป ไอคอน สี โหมด standalone และ shortcuts
sw.js                   service worker (precache + offline)
icons/                  ไอคอน 192 / 512 / maskable / apple-touch / favicon
```

## ต้องเสิร์ฟผ่าน HTTPS เท่านั้น

Service worker ทำงานได้เฉพาะบน `https://` หรือ `http://localhost`
เปิดไฟล์แบบ `file://` หน้าเว็บยังอ่านได้ปกติ แต่จะไม่มี offline และไม่มีปุ่มติดตั้ง

ลองในเครื่อง:

```bash
cd baymax-pwa
python3 -m http.server 8080
# เปิด http://localhost:8080
```

ขึ้นโฮสต์จริง — อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages, Netlify, Vercel, Cloudflare Pages
หรือ S3 + CloudFront ก็ได้ ไม่ต้องมี build step

> ถ้าวางไว้ใน subpath เช่น `example.com/baymax/` ใช้ได้เลย เพราะทุก path เป็นแบบ relative (`./`)
> ยกเว้นค่า `id` ใน manifest ที่ตั้งไว้เป็น `/baymax-manual/` — แก้ให้ตรง path จริงหรือลบออกก็ได้

## ตรวจว่าติดตั้งได้จริง

Chrome DevTools → **Application**
- Manifest: ต้องไม่มี error และเห็นไอคอนครบ
- Service Workers: สถานะ `activated and is running`
- ติ๊ก **Offline** ใน Network แล้ว reload — หน้าต้องยังขึ้นเหมือนเดิม
- Lighthouse → หมวด PWA ควรผ่านทั้งหมด

## UI ชวนติดตั้งทำงานยังไง

| สถานการณ์ | สิ่งที่เกิดขึ้น |
|---|---|
| Chrome/Edge/Android เข้าเกณฑ์ติดตั้ง | ดัก `beforeinstallprompt` แล้วโชว์การ์ดชวนติดตั้งหลังเข้าหน้าราว 2 วินาที ปุ่ม "ติดตั้งเลย" เรียก prompt ของระบบ |
| iOS Safari | ไม่มี `beforeinstallprompt` — การ์ดจะเปลี่ยนเป็นวิธีทำเอง (แชร์ → เพิ่มไปยังหน้าจอโฮม) |
| กด "ไว้ก่อน" หรือปิด | จำไว้ใน localStorage แล้วไม่กวนอีก |
| เปิดจากแอปที่ติดตั้งแล้ว | ซ่อนการ์ด และเปลี่ยนข้อความท้ายเล่มเป็นสถานะติดตั้งแล้ว |
| ไม่มีสัญญาณ | ขึ้นป้าย "Offline · อ่านจากเครื่องอยู่" ที่หัวหน้า |
| มีเวอร์ชันใหม่ | ขึ้น toast "มีคู่มือเวอร์ชันใหม่แล้ว" พร้อมปุ่มโหลดใหม่ |

## เกมในเล่ม — ซ้อมปะรอยรั่ว (หัวข้อ 05)

มินิเกมอาร์เคดที่ต่อยอดจากหัวข้อการดูแลรักษา รูจะโผล่บนตัวหุ่นเรื่อย ๆ ต้องแตะให้ทันก่อนลมหมด

- รูที่เปิดค้างดูดลมออกเรื่อย ๆ ยิ่งเปิดพร้อมกันหลายรู ยิ่งรั่วเร็ว
- ปะเร็วได้คะแนนมากกว่า (12–42 แต้ม) พร้อมได้ลมคืน 4%
- อัตราการเกิดรูเร่งขึ้นตามเวลา จาก 1.5 วิ เหลือ 0.56 วิ
- เทปกาวที่ปะแล้วค้างอยู่บนตัว เห็นร่องรอยการเอาตัวรอดทั้งรอบ
- เล่นได้ทั้งเมาส์ นิ้ว และคีย์บอร์ด (Tab + Enter) มี haptic บนมือถือ
- สลับแท็บ/ย่อแอปแล้วเกมพักให้ ไม่นับแพ้

**ระบบสะสม** — 6 ชิปการดูแลปลดล็อกตามคะแนน (150 / 350 / 600 / 900 / 1300 / 1800)
พร้อมยศ 5 ขั้นตั้งแต่ "ผู้ช่วยฝึกหัด" ถึง "ตำนานเทปกาว"

ข้อมูลที่เก็บในเครื่อง (localStorage — ไม่ส่งออกไปไหน):

| key | เก็บอะไร |
|---|---|
| `baymax.best` | คะแนนสูงสุด |
| `baymax.chips` | ชิปที่ปลดล็อกแล้ว |
| `baymax.install.dismissed` | เคยปิดคำชวนติดตั้งไปแล้วหรือยัง |

ล้างข้อมูลเกม: `localStorage.clear()` ใน console

## อัปเดตเนื้อหา

แก้ `index.html` แล้วเปลี่ยน `VERSION` ใน `sw.js` (เช่น `v1.0.1`)
แคชเก่าจะถูกลบตอน activate และผู้ใช้จะเห็น toast ให้กดโหลดใหม่
