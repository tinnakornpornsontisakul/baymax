# คู่มือผู้ใช้ Baymax — PWA ไฟล์เดียว

`index.html` ไฟล์เดียวจบ ทั้งเนื้อหา ไอคอน manifest และเกมสองเกมอยู่ในนั้นหมด
ไม่มี build step ไม่ต้องลงอะไร ไม่ต้องรันเซิร์ฟเวอร์

## ขึ้น GitHub Pages

1. อัปโหลด `index.html` เข้า repo (จะวางที่ root หรือโฟลเดอร์ไหนก็ได้)
2. Settings → Pages → Source เลือก **Deploy from a branch** → branch `main` โฟลเดอร์ `/ (root)`
3. รอสักครู่แล้วเปิด `https://<username>.github.io/<repo>/`

เท่านี้จบ ทั้งเว็บและปุ่มติดตั้งแอปทำงานเลย

## `sw.js` — ไฟล์เสริม ไม่ใส่ก็ได้

วางไว้ข้าง ๆ `index.html` เมื่อไหร่ คู่มือจะเปิดอ่านได้ตอนไม่มีเน็ต
ถ้าไม่วาง ทุกอย่างยังทำงานปกติ แค่ไม่มีโหมด offline (โค้ดจับ error ไว้ให้แล้ว)

| ใส่อะไรบ้าง | ได้อะไร |
|---|---|
| `index.html` อย่างเดียว | เว็บครบทุกอย่าง + เพิ่มไปหน้าจอโฮมบน iOS ได้ |
| `index.html` + `sw.js` | ได้เพิ่ม: อ่าน offline, ปุ่มติดตั้งบน Chrome/Edge/Android, แจ้งเตือนเวอร์ชันใหม่ |

## เปิดดูในเครื่องเฉย ๆ

ดับเบิลคลิก `index.html` ได้เลย เนื้อหาและเกมทำงานครบ
(เฉพาะโหมด offline กับปุ่มติดตั้งที่ต้องเปิดผ่าน https หรือ localhost ตามข้อกำหนดของเบราว์เซอร์ ไม่ใช่ข้อจำกัดของไฟล์)

## ในเล่มมีอะไร

- หน้าลงทะเบียนผู้ดูแลก่อนเข้าเว็บ พร้อมวิธีติดตั้งแอปทุกแพลตฟอร์มในการ์ดเดียวกัน
- 01 เปิดใช้งานครั้งแรก · 02 โหมดการทำงาน (หุ่นขยับตามโหมด)
- 03 เกมซ้อมปะรอยรั่ว — สะสมชิป 6 อัน มียศ 5 ขั้น
- 04 เกมซ้อมรบกับเชื้อโรค — อาร์เคดยิง Baymax เดินได้ ยิงหมัดจรวด มีเวฟ
- 05 ตารางแก้ปัญหา + บัตรรับประกันที่กรอกชื่อไว้แล้ว

ข้อมูลทั้งหมด (ชื่อ คะแนน ชิป) เก็บใน localStorage ของเครื่องคุณเอง ไม่มีเซิร์ฟเวอร์ ไม่ส่งออกไปไหน

## แก้เนื้อหา

แก้ `index.html` ตรง ๆ ได้เลย ถ้าใช้ `sw.js` ด้วย ให้เปลี่ยนเลข `VERSION` ข้างในเป็นเลขใหม่
คนที่ติดตั้งไว้แล้วจะเห็นแถบ "มีคู่มือเวอร์ชันใหม่แล้ว" ให้กดโหลดใหม่
